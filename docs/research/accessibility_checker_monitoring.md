# Accessibility Checker Monitoring
## Introduction
To ensure the Accessibility Checker tool is functioning as expected and providing value to small business owners and solo entrepreneurs, we need to set up monitoring and alerting for key business metrics. This document outlines the approach for monitoring and alerting, focusing on conversion rates and revenue.

## Key Business Metrics
The following metrics are crucial for the Accessibility Checker tool:
* Conversion rates: The percentage of visitors who complete a desired action, such as signing up for a free trial or purchasing a license.
* Revenue: The total income generated by the tool, including sales of licenses and any other revenue streams.

## Monitoring Tools
To monitor these metrics, we will utilize the following tools:
* Google Analytics: For tracking website traffic, conversion rates, and revenue.
* Sentry: For monitoring application errors and performance issues.

## Google Analytics Setup
To set up Google Analytics, follow these steps:
1. Create a Google Analytics account and set up a new property for the Accessibility Checker tool.
2. Install the Google Analytics tracking code on the `index.html` page.
3. Configure goals and events to track conversion rates, such as:
	* Goal: Free trial sign-up
	* Event: Purchase of a license
4. Set up e-commerce tracking to monitor revenue.

## Sentry Setup
To set up Sentry, follow these steps:
1. Create a Sentry account and set up a new project for the Accessibility Checker tool.
2. Install the Sentry SDK in the `worker.js` file.
3. Configure error tracking and performance monitoring.

## Alerting
To set up alerting for key business metrics, we will use the following tools:
* Google Analytics Alerts: For alerting on changes in conversion rates and revenue.
* Sentry Alerts: For alerting on application errors and performance issues.

## Google Analytics Alerts
To set up Google Analytics alerts, follow these steps:
1. Navigate to the Google Analytics dashboard and click on "Admin".
2. Click on "View" and then "Goals".
3. Click on "Alerts" and then "New Alert".
4. Configure alerts for changes in conversion rates and revenue, such as:
	* Alert: Conversion rate decrease by 10% in the last 24 hours
	* Alert: Revenue decrease by 20% in the last 7 days

## Sentry Alerts
To set up Sentry alerts, follow these steps:
1. Navigate to the Sentry dashboard and click on "Issues".
2. Click on "Alerts" and then "New Alert".
3. Configure alerts for application errors and performance issues, such as:
	* Alert: Error rate increase by 20% in the last 24 hours
	* Alert: Average response time increase by 50% in the last 7 days
