## The Limitations of Static Parsing
Static parsing involves analyzing the HTML and CSS code of a website to identify potential accessibility issues. While this approach can detect some issues, it has significant limitations. Static parsing can't account for the complexities of modern web development, such as:

* Dynamically generated content
* CSS media queries
* JavaScript-generated styles
* Complex layouts and positioning

These limitations can lead to false positives or false negatives, making it difficult to trust the results of static parsing.

## The Power of Rendered-DOM + Computed-Style Contrast Checking
Our Accessibility Checker tool takes a different approach. By using rendered-DOM + computed-style contrast checking, we can analyze the actual visual representation of a website, taking into account all the complexities of modern web development.

Here's how it works:

1. **Rendered-DOM**: We render the website in a headless browser, allowing us to analyze the actual DOM structure and styles applied to each element.
2. **Computed-Style**: We compute the styles applied to each element, taking into account all the CSS rules, media queries, and JavaScript-generated styles.
3. **Contrast Checking**: We then check the contrast between the text and background colors of each element, using the computed styles to determine the actual visual representation.

This approach provides a much more accurate and reliable way to identify accessibility issues, including:

* Insufficient color contrast
* Inadequate font sizes
* Poorly designed layouts and positioning

## Benefits of Rendered-DOM + Computed-Style Contrast Checking
The benefits of this approach are numerous:

* **More accurate results**: By analyzing the actual visual representation of a website, we can identify issues that static parsing might miss.
* **Fewer false positives**: Our approach reduces the number of false positives, giving you more confidence in the results.
* **Improved user experience**: By identifying and addressing accessibility issues, you can improve the overall user experience for all visitors to your website.
