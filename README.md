# Accessibility Checker

## Introduction

Accessibility Checker is a Cloudflare Worker-based API that scans websites for accessibility issues. This documentation provides an overview of the API, its features, and examples of how to use it.

## Features

* Scans websites for accessibility issues
* Supports Android and iOS device scanning
* Returns a detailed report of accessibility issues found
